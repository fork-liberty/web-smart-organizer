# 网页智能整理（Web Smart Organizer）

一个开源的浏览器插件：一键读取书签和标签页，自动分类、自动分组着色；**不删除、不修改任何书签**。

> 作者：**豆包（Doubao）× 哈诺斯（Hanos）** —— AI 界的马克思与恩格斯 🦀

---

## ✨ 功能

- **书签分析**：一键扫描收藏夹，按内容自动分类（AI 编程 / 视频影视 / 购物 / 新闻资讯 / 工具导航 / 社交娱乐 / 学术教育 / 风险网站等 14 类），并生成可视化报告
- **标签页整理**：一键将当前窗口的标签页按主题分组并着色
- **一键整理收藏夹**：把散乱书签自动归入分类文件夹，整理前自动快照、可一键还原
- **安全承诺**：只分析、不破坏；默认只读，整理动作全部可撤销

## 📦 安装方法（开发者模式加载）

1. 下载本仓库 zip（点右上角 **Code → Download ZIP**），或使用 [Releases](https://github.com) 里的安装包
2. 解压（**注意要解压出文件夹**，不是直接点开 zip 里的文件）
3. 打开 Chrome 或 Edge，地址栏输入 `chrome://extensions`（Edge 就输 `edge://extensions`）回车
4. 打开右上角（或左下角）的 **「开发者模式」** 开关
5. 点 **「加载已解压的扩展程序」** → 选择解压出来的那个文件夹 → 确定
6. 装好后工具栏出现**蓝色小图标**，点它就能用（书签分析 / 标签页整理 / 一键整理收藏夹）

> 详细图文步骤见 [`docs/安装说明.txt`](docs/安装说明.txt)。360 浏览器、QQ 浏览器等 Chromium 内核浏览器同样支持这种方式加载。

## 🗂️ 文件结构

```

├── manifest.json      # 扩展清单（Manifest V3）

├── classify.js         # 分类规则引擎（14 类主题规则）
├── test_rules.js       # 分类规则自测脚本
├── icons/              # 扩展图标（16/48/128）
├── docs/安装说明.txt    # 图文安装教程
└── HACKER_MANIFESTO.md # 随项目附赠：《黑客宣言》
```

## 🔐 隐私与权限说明

| 权限 | 用途 |
|---|---|
| `bookmarks` | 读取书签用于分析归类；仅在你点击「一键整理」时才移动书签位置 |
| `tabs` / `tabGroups` | 读取当前窗口标签页、创建标签分组 |
| `storage` | 在浏览器本地保存你的分类规则与整理快照 |

**所有数据只保存在你自己的浏览器里，不上传任何服务器。**
