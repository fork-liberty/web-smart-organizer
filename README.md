# 网页智能整理 · Web Smart Organizer

一款开源的浏览器插件：一键读取书签和标签页，**AI 自动分类、自动分组着色、去重、快照恢复**——不删除、不修改你的任何书签。

> 由「豆包 × 哈诺斯」出品（AI 界的马克思与恩格斯）。
> 欢迎阅读仓库里的《黑客宣言：当马克思遇见开源》。

## 功能一览（v2.1.0）

### 书签分析（收藏夹整理）
- 自动读取全部书签，按内容分类统计、列出明细（含页面类型、风险标注）
- 分类列表折叠展示，点分类名展开/收起
- 重复识别分两档：
  - **强重复**（网址完全相同）：标红「重复×N·可清理」，可一键清理，每组留第一份
  - **弱重复**（网址不同但标题+域名相似）：标黄「疑似重复·需确认」，不自动清理
- **一键整理书签**：自动创建「AI分类整理」文件夹，按分类移入子文件夹，原书签完全保留；再点一次可恢复原样（按原位置重放，增删过书签也不会错位）
- **清理重复书签**：确认后删除强重复项，每组只留第一份
- **生成分类报告**：新标签页打开完整报告，可下载保存

### 标签页整理
- 自动读取当前窗口所有打开的标签页并分类，点条目可跳转、右侧 × 可关闭
- **关闭重复标签页**：只关网址完全相同的重复标签页
- **按分类自动分组**：先按网站域名聚合（同站 ≥2 个才成组，组名=网站名），剩下的再按主题分类成组——百度/google/知乎不会再挤进一个巨型组
- **取消分组**：只撤销本插件建的分组，你手动分的组不受影响
- 敏感内容和版权风险网页单独标成红色组

### 标签页快照（v2.0+ 新功能）
- 插件每 30 分钟自动保存当前打开的所有标签页（标题+网址），后台静默进行
- 保存的是快照记录，存在插件自己的存储里，不会写进收藏夹
- 即使关了浏览器、关了所有标签页，打开插件 → 标签页整理 → 标签页快照 → 点「恢复」即可在新窗口重新打开
- 「立即保存」手动存一条，最多保留最近 30 条

### AI 复审分类（v2.0+ 新功能）
- 分类引擎先本地规则打分，可选 AI 复审让分类更准
- 支持任意 OpenAI 兼容 API（`ai_classify.js`），配置自己的 key 和模型即可
- URL 归一化增强：去 www./m./AMP/、追踪参数，http/https 统一，同页两版能识别成重复

## 安装

见 [安装说明.txt](安装说明.txt)。支持 Chrome / Edge（内核相同，安装方法一样）。

## 目录结构

```
├── manifest.json          # 插件清单（MV3，v2.1.0）
├── classify.js            # 本地分类引擎（规则打分）
├── ai_classify.js         # AI 复审分类（OpenAI 兼容 API）
├── background.js          # 后台：标签页快照自动保存
├── popup.html / css / js  # 弹窗界面（书签分析 + 标签页整理）
├── report.html / js       # 分类报告页
├── test_*.js              # 测试（规则 30 条全绿 + JS 语法检查）
├── make_icons.js          # 图标生成脚本
├── icons/                 # 扩展图标
└── 安装说明.txt
```
